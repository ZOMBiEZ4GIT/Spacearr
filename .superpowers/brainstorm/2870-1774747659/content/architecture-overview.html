Data Flow
1. Scan
Filesystem scan for file sizes, codecs, bitrates via MediaInfo
2. Enrich
Match files to Sonarr/Radarr items for metadata & quality profiles
3. Visualize
Treemap + table with bitrate heatmap, filterable & sortable
4. Act
Delete, re-search, quality swap, bulk operations via ARR APIs

Key Design Decisions

Stack
.NET 8 + React + SQLite — same as Sonarr/Radarr
Heatmap
Bitrate as default color, switchable to quality/codec/resolution
Discovery
Hybrid: filesystem scan + Sonarr/Radarr API enrichment
Service Model
Full standalone — own port, own DB, background scanning
